# Imagens do CarePoint

Os arquivos `medica-carepoint.png`, `fisioterapeuta-carepoint.png`, `clinica-carepoint.png` e `cuidado-domiciliar-familia.png` foram gerados especificamente para este projeto com a ferramenta integrada de geração de imagens.

O arquivo `equipe-saude-carepoint.png` é uma fotografia fornecida pela própria equipe Vitalux para uso na página “Nossa Equipe”.

Os diretórios `profissionais/` e `clinicas/` contêm imagens originais geradas exclusivamente para os dados demonstrativos do CarePoint. Os arquivos foram otimizados em WebP e podem ser substituídos sem alterar o backend, desde que os caminhos usados pelo seed sejam mantidos.

- Não foram copiados de sites, bancos de imagens ou das referências visuais fornecidas.
- As pessoas e a clínica retratadas são fictícias.
- Não possuem marcas, logotipos ou textos de terceiros.
- Podem ser substituídos por fotos autorizadas no cadastro administrativo.
